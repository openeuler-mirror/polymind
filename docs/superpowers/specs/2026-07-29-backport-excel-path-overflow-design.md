# Backport Excel 文件选择器长路径溢出修复

## 背景

Backport 页面中的“选择服务器上的 Excel 文件”弹窗使用滚动区域展示目录内容。当文件路径较长时，滚动区域内容的固有宽度会超过弹窗宽度，导致文件列表边框和内容横向溢出。

## 目标

- 文件列表始终限制在弹窗可用宽度内。
- 文件名和路径保持单行展示，空间不足时显示省略号。
- 用户悬停文件名或路径时可以查看完整文本。
- 右侧文件类型标签保持可见且不被压缩。
- 当前目录输入框仍可正常编辑和横向滚动。
- 不改变文件浏览、目录跳转或 Excel 文件选择逻辑。

## 设计

修改 `components/tool-panel/backport-page.tsx` 中的 Excel 文件选择弹窗：

1. 为弹窗内容、滚动区域外框和文件列表补充明确的宽度约束与溢出裁剪。
2. 为每个文件条目补充 `min-width: 0`，使其子元素能够在 Flex 和 ScrollArea 布局中正确收缩。
3. 文件信息容器占据剩余空间并裁剪溢出；右侧类型标签禁止收缩。
4. 文件名和完整路径继续使用单行省略，并通过原生 `title` 属性提供完整内容。
5. 弹窗宽度兼顾窄屏，最大宽度保持现有视觉规格。

## 验证

- 使用超长目录名和文件名检查弹窗及列表不再横向溢出。
- 检查文件名、路径均出现正确省略效果和悬停提示。
- 检查“打开”“返回上级”、目录进入和 Excel 文件回填行为不变。
- 运行项目 TypeScript 静态检查。

## 非目标

- 不引入自定义 Tooltip 组件。
- 不修改后端路径浏览 API。
- 不重构 Backport 页面或通用 ScrollArea 组件。
